## 見つかった問題と再確認の対象

- #709: 注釈を省いた通常fnや公開letを受理する実装と仕様の差を、本文は
  0.61.19の制限として正しく示している。修正されたcanonical releaseを確認した後、
  日英の注意を新しい診断と直し方へ更新する。未公開の挙動を先に説明しない。
- #740: 改稿後の正例・拒否例を、以前のpanel数、段落数、短い部分適用例だけを
  要求するbrowser testが受け付けなかった。本文を古い形へ戻さず、実行検証済みの
  source・結果・診断と、日英・navigation・狭幅の検査を対応させる。
- この読み直しでは、6ページの基本例を理解するために未説明のADT、match、
  Rust/Haskellの知識を先に要求する箇所は見つからなかった。実読者が同じように
  読めると実証したものではなく、後から得た疑問は該当ページへ戻して再確認する。

## 次の対象と説明基準

値と関数で使った「身近な入力→普通の操作→結果→詳しい規則と失敗例」を維持する。
正例はそのまま保存・実行できる形を使い、表示のための入口も説明する。
型注釈・関数型・実行するEffectを一度に暗黙の前提にしない。

次の対象は既存#705のデータの選択肢とmatch、#710の不在・失敗・Effectとする。
両方とも既存#628 / #630のページ台帳へ接続されており、重複Issueを作らない。
データの形と値の作り方を先に説明してからmatchへ進む。失敗はTSのtry/catchから
入り、値の不在、失敗を表す値、処理の実行を分ける。すでに改稿された本文は同じ
問いで検査し、未確認のページをこのpilotの結果だけで受け入れ済みにしない。

実行・診断とbrowserの最終統合結果は、#701、#706、#740の記録と対応させる。
この文書だけで全106ページ、非コア245記事、全APIの確認済みとはしない。
