# Docs Reboot の導線

Homeは玄関。Hero、一つのコードと出力、短い紹介、First RunとDocsへのリンク。
Docsからは目的と技術名で同じ記事へ進む。

| 読者の目的 | 入口 |
| --- | --- |
| 関数を書き、渡し、つなぐ | 関数と記法 |
| 欠如を残して値を変え、組み合わせる | 文脈のある値 |
| 型・制約・使えるtargetを調べる | API Reference → module → declaration anchor |
| 手元で動かす | First Run |
| 入力を変えて試す | Examples / 独立したPlayground・Tour |
| 更新と配布を調べる | Releases |

日英は同じsourceと意味を共有し、言語切替は同じ記事へ向かう。
本文・sidebar・module内索引はno-JSでも読める。
Mobileの全体menuと記事内menuを分け、長いsignatureはコード領域内で横scrollする。
旧記事の章構造・URL・ページ数・fragmentは要件にしない。
検索とinline実行は追加体験として独立に扱う。
