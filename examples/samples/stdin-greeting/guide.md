このサンプルを選ぶ理由: 標準入力から複数行を読み込みつつ、計算部分を入出力から切り離して失敗を型でまとめたいときに選びます。

下の Input 欄にある「名前,点数」の CSV データを末尾まで読み込み、平均点や最高点、評価の集計と、数値でない行や範囲外の行を行番号付きで知らせます。

## この画面で試すこと

- 下の Input 欄で `Mio,abc` を `Mio,88` に書き換えて Run を押し、エラー行が減って集計人数が増えるのを見る
- Try next の「合格ラインを 70 点に上げる」を押し、`Hana: 64 点` が再試になり合格人数が変わるのを見る
- 「S 判定を 85 点以上に広げる」を押し、`Sora: 85 点` の判定が変わるのを見る

## コードの読みどころ

1. `type AppError` と `mapError`: 読み込みの失敗（`StdinError`）と出力の失敗（`ConsoleError`）を `AppError` の 1 つにそろえて `fails AppError` で宣言します。
2. `readAllLines`: `readLine ()` が `Nothing`（入力の終わり）を返すまで再帰で配列へ集めます。
3. `buildReport` と `parseScoreLine`: 入出力を持たない純粋な関数だけで CSV の検証・集計・行番号付きメッセージ組み立てを行います。
4. `main`: 読む処理と出す処理だけをつなぎ、計算の詳細は一切持ちません。
