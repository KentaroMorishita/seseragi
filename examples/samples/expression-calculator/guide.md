このサンプルを選ぶ理由: 木の形のデータを型で表し、`match` でたどって処理する形を見たいときに選びます。

式 `1 + 2 × 3` を、`Apply (Plus, Num 1, Apply (Times, Num 2, Num 3))` という木で表します。計算は、木を下からたどって組み立てます。0 で割る式は、例外ではなく `Either` の失敗として返します。

## この画面で試すこと

- 3 つ目の式が「計算できません」になる理由を読む。Try next の「割る数を 2 にする」を押すと、計算できるようになります
- 「式を一つ足す」を押し、整数の割り算が小数点以下を切り捨てるのを見る
- `type Op` に `Mod` を足してみる。`symbol` と `calculate` が全部の演算子を扱っていないことを、エラーが教えてくれます

## コードの読みどころ

1. `type Op` と `type Expr`: 演算子を型で並べ、式を「数」か「演算子と左右の式」で表します。`Expr` は自分自身を含む、再帰する型です。
2. `evaluate`: `do` で左右を計算してから組み合わせます。どちらかで失敗すると、その先は計算しません。
3. `match (op, b)`: 演算子と割る数をタプルにして、「割り算で 0」の場合だけを取り出します。
4. `report`: 結果が `Right` か `Left` かで、表示する文を分けます。
