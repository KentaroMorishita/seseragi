このサンプルを選ぶ理由: `Array` と `List` をパターンマッチで先頭から順にたどる書き方と、両者の違いを見比べたいときに選びます。

各駅の区間時間（`Leg`）を先頭から順に足し上げ、駅ごとの累計時間と、Array・List それぞれの再帰による合計時間を出します。

## この画面で試すこと

- Try next の「終点に三島駅を足す」を押し、路線表示と合計時間が更新されるのを見る
- 「新横浜から小田原を 12 分に縮める」を押し、途中の区間変更が以降の累計時間にも反映されるのを見る
- `totalMinutesArray` の `[] -> elapsed` の行を消して、空ケースの網羅性チェックが働くことを確かめる

## コードの読みどころ

1. `totalMinutesArray`: `[]` と `[head, ...tail]` の 2 つを並べることで、空の配列と要素がある配列を漏れなく扱います。
2. `totalMinutesList`: `List` ではバッククォート付きの `` `[] `` と `` `[head, ...tail] `` を使います。`tail` は元のリストを共有するため、先頭からたどる再帰に向いています。
3. `formatTimeline`: 累計時間 `elapsed` と出力行 `acc` を引数で引き継ぎながら、末尾再帰で各駅の表示を組み立てます。
