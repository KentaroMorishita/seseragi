SESERAGI / PROGRAMMING LANGUAGE

宣言と式で、
プログラムを書く。

Seseragiは、データの形から状態やUIまで、同じ型と構文で書けるプログラミング言語。まずは短いコードから、書き方を見てみよう。

ドキュメントを読む →Playgroundで試す ↗
CODE, NOT JUST WORDS

分岐も、
ひとつの式になる。

matchは条件に合った分岐の値を返す。returnを挟まなくても、その結果がそのまま関数の値になる。こんな小さな違いが、書き方を変えていく。

この記法を読んでみる →
fizzbuzz.ssrgSource ↗
fn fizzBuzz number: Int -> String =
  match (number % 3, number % 5) {
    (0, 0) -> "FizzBuzz"
    (0, _) -> "Fizz"
    (_, 0) -> "Buzz"
    _ -> `${number}`
  }

pub effect fn main = for number <- 1 ..= 30 {
  println $ fizzBuzz number
}
1   2   Fizz   4   Buzz   Fizz ...

まずは、ひとつ書いてみよう。
