The Seseragi programming language — 01

Seseragi.

文ではなく、式で書く。

Seseragiは、宣言と式でプログラムを組み立てる言語。関数を作り、値を渡し、組み合わせる。書き方の違いを、まずは短いコードから見てみよう。

fn square n: Int -> Int = n * n

fn norm2 x: Int -> y: Int -> Int =
  square x + square y

pub effect fn main =
  println $ show (norm2 3 4)
