CODE, NOT JUST WORDS

A branch is
an expression.

`match` produces a value from the chosen branch. There is no `return` statement between the result and the function.

Read this example in context →
fizzbuzz.ssrg
Try in Playground ↗ 
fn fizzBuzz number: Int -> String =
  // A tuple lets one match classify both divisibility rules.
  match (number % 3, number % 5) {
    (0, 0) -> "FizzBuzz"
    (0, _) -> "Fizz"
    (_, 0) -> "Buzz"
    _ -> `${number}`
  }

pub effect fn main = for number <- 1 ..= 30 {
  println $ fizzBuzz number
}
