04 / EFFECT

Effect and do

Computing a value and displaying it are different jobs. Keeping Effects separate makes the calculation easier to understand.

Compute the values first.

Clean up a few labels, count their characters and calculate the total. Nothing needs to be printed yet.

calculate.ssrg
Try in Playground ↗ 
let labels = [" Build ", "bundle", "CHECK", "run"]
let lengths = map (\label -> text.lengthScalars (text.trim label)) labels
let total = reduce 0 (+) lengths

Then compose the effects.

main handles output. do lets you compose two print Effects in sequence.

main.ssrg
Try in Playground ↗ 
pub effect fn main = do {
  println (show lengths)
  println (show total)
}

This is not a return to imperative statements. do is notation for effectful composition, not a decorative semicolon.

How do and other operators relate

Dependent composition and independent combination are not identical. Explore do , >>= and <*> in the context of types, failures and Effects.
