02 / PATTERN MATCHING

Data and match

A branch can still be an expression. match inspects the shape of a value and produces a result from a matching arm.

Choose a value, not a statement.

FizzBuzz works nicely as a tuple pattern. The remainders for 3 and 5 are checked together.

fizzbuzz.ssrg
Try in Playground ↗ 
fn fizzBuzz number: Int -> String =
  // A tuple lets one match classify both divisibility rules.
  match (number % 3, number % 5) {
    (0, 0) -> "FizzBuzz"
    (0, _) -> "Fizz"
    (_, 0) -> "Buzz"
    _ -> `${number}`
  }

pub effect fn main = for number <- 1 ..= 30 {
  println $ fizzBuzz number
}
1 2 Fizz 4 Buzz Fizz …

(0, 0) matches both divisibility rules. (0, _) ignores the second component. The last _ catches what remains. Each arm returns a string, and the whole function returns that value.

Producing a value is not printing it.

fizzBuzz simply returns text. main uses for and println $ fizzBuzz number to print each result. Pure computation and Effects stay separate.

Change one branch.

Try replacing "Fizz" with something else. Open the whole program and run it.

How match is evaluated

The first matching arm provides the expression’s result. Tuple patterns can examine multiple values together. Refer to the compiler and specification for exhaustive matching and precise type constraints.
