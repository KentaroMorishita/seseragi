01 / Function & application

関数 — 小さく書いて、
組み合わせる。

関数って、長い処理をまとめるためだけのものじゃない。小さく分けて、あとで組み合わせる。その方が、むしろコードが素直になることもある。

まず、一つ書いてみる。

ある数を二乗するだけなら、関数はこれだけでいい。

functions / square.ssrg01
fn square n: Int -> Int = n * n

fnで関数を定義する。n: Intは受け取る数とその型で、-> Intが結果の型。=の右が計算の本体だ。

戻り値のためにreturnを書く必要はない。式そのものが値になるからだ。

そのまま、組み合わせる。

例えば座標の距離を二乗した値が欲しいなら、さっきのsquareを二回使える。

functions / main.ssrgSESERAGI
fn square n: Int -> Int = n * n

fn norm2 x: Int -> y: Int -> Int =
  square x + square y

pub effect fn main =
  println $ show (norm2 3 4)
result / distance² of (3, 4)25

norm2 3 4は2つの引数を空白で渡す呼び出し。3² + 4²だから結果は25。$は右側の計算結果を、そのまま左の関数に渡す記法。無理にパイプラインへ変えなくても、こう書けば十分読みやすい。

気になったら、規則も見てみよう。

関数の型、引数の適用順、部分適用。詳しい規則は、必要になったときに引ければいい。

この例で使った記法のメモを見る

fnは関数宣言。->は引数と結果の型。f xは空白で関数適用。f $ g xはf (g x)と同じ意味。
