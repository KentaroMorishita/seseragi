関数と記法

Seseragiは、処理を一つずつ実行する文ではなく、値を返す式を組み合わせて書く。まず小さな関数から、読み方をつかんでみよう。

関数の結果は、最後の式。

FizzBuzzなら、3と5で割り切れるかどうかを見て、文字列を作る。Seseragiではどの分岐も値を返すので、そのまま関数の結果にできる。

fizzbuzz.ssrgSource ↗
fn fizzBuzz number: Int -> String =
  match (number % 3, number % 5) {
    (0, 0) -> "FizzBuzz"
    (0, _) -> "Fizz"
    (_, 0) -> "Buzz"
    _ -> `${number}`
  }

pub effect fn main = for number <- 1 ..= 30 {
  println $ fizzBuzz number
}
1   2   Fizz   4   Buzz   Fizz ...

fn fizzBuzz number: Int -> Stringは、「整数をひとつ受け取り、文字列を返す関数」という宣言。matchは値の形を上から調べ、一致した分岐の右側を結果として返す。_は、それまでに扱わなかった残りの場合だ。

呼ぶときは、引数を渡す。

fizzBuzz numberが関数適用。括弧で囲んだ引数リストを作るのではなく、関数の後ろに値を書く。println $ fizzBuzz numberでは、$が右側の計算全体をprintlnへ渡している。

ここではmainが出力を扱う。文字列を作るfizzBuzzとは役割が分かれているんだ。
