03 / COMPOSITION

Composing functions

There are several ways to compose functions. A pipeline is not the only answer. Choose the notation that makes the structure easiest to follow.

One calculation, three shapes.

Search for commands and add a display badge. After naming the filter pick , these three expressions produce the same value — and emphasize different reading directions.

syntax-reader-pipelines.ssrg
Try in Playground ↗ 
let pick = arrays.filter (matches "b")
let nested = map badge (pick commands)
let compact = map badge $ pick commands
let choices = commands |> pick |> map badge

Ordinary application nests function calls. $ groups an expression on the right. |> puts a value first, then follows its transformations. Choose by meaning, not by a pipeline quota.

An absent result can stay absent.

arrays.find may not find anything. <$> lets you apply badge only when there is a value.

find-and-map.ssrg
Try in Playground ↗ 
let picked = arrays.find (matches "b") commands
let suggestion = badge <$> picked
let missing = arrays.find (matches "z") commands
let absentLabel = badge <$> missing

badge <$> picked transforms the value when present, preserving absence otherwise. That is why <$> belongs in this example.

Compare all three in Playground ↗ Look up notation →
Operator roles at a glance

$ groups application, |> pipelines values and <$> maps within a context. <*> , >>= and do support other forms of composition.
