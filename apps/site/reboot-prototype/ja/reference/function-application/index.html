関数適用

関数適用は、関数のあとに値を空白で並べて書く。左結合、型、評価順序をここで調べられる。

構文型と部分適用評価規則Unitと型引数仕様出典

構文と結合

add 1 2 は (add 1) 2 と同じ。カンマ区切りの add(1, 2) はSeseragiの複数引数呼び出し構文ではない。

f value関数へ一つの値を適用
add 1 2左結合 — (add 1) 2 と同じ
identity<String> value型引数はcalleeと空白を空けない

型と部分適用

引数を途中まで渡すと、残りを受け取る関数が残る。add の型は Int -> Int -> Int、add 1 は Int -> Int。これは特別な呼び出しモードではなく、関数が入れ子になっているから。

完全なプログラムでは、直接2つ渡した結果と、部分適用してから残りを渡した結果を比べられる。

pilot-currying.ssrg
Playgroundで試す ↗
fn add left: Int -> right: Int -> Int = left + right

let direct = add 1 2
let addOne = add 1
let answer = addOne 2

pub effect fn main = println `${direct}, ${answer}`
実行結果3, 3

評価順序

引数は左から右へ、一度ずつ評価する。関数本体は適用されたときに評価される。Effectの中身が実行境界まで実行されないこととは、区別して考えよう。

Unit引数・型引数

引数を明示しない fn clock -> Instant = ... も、意味上は Unit 引数を一つ持つ。呼び出しは clock ()。型引数は identity<String> value のように関数名へ空白なしで続ける。
