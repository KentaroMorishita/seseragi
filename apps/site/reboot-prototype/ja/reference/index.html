記法リファレンス

記号の名前だけ思い出したいときに。読まなくていい章は、飛ばしてしまおう。正確な型や制約は各記事とコンパイラ仕様で確認できる。

fn
関数を宣言する

fn key name: String -> String = …

↗
f x
関数へ値を渡す

key " Build "

↗
match
分岐を値として返す

match (number % 3, number % 5) { … }

↗
$
右側の式をまとめて適用する

map badge $ arrays.filter (matches "b") commands

↗
|>
値から変換を追う

commands |> arrays.filter (matches "b") |> map badge

↗
<$>
文脈の中の値を変換する

badge <$> picked

↗
do
Effectの合成を読む

pub effect fn main = do { … }

↗
<*>
独立した文脈付き引数を組み合わせる

Functor / Applicative

↗
>>=
前の結果に依存する合成
