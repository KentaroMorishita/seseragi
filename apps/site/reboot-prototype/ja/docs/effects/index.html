04 / EFFECT

Effectとdo

値を計算することと、画面に出すことは別。Effectを一緒くたにしないと、何を計算する関数なのかが見えてくる。

まずは値だけを計算する。

ラベルの余分な空白を取り除いて、文字数を数える。ここまでは単なる値の計算。 map で配列のそれぞれに処理を適用し、 reduce で合計している。

calculate.ssrg
Playgroundで試す ↗ 
let labels = [" Build ", "bundle", "CHECK", "run"]
let lengths = map (\label -> text.lengthScalars (text.trim label)) labels
let total = reduce 0 (+) lengths

実行する処理は、別にまとめる。

結果を表示するのは main の仕事。 do の中で二つの出力を順に組み立てられる。

main.ssrg
Playgroundで試す ↗ 
pub effect fn main = do {
  println (show lengths)
  println (show total)
}

この do は単なるセミコロンの代わりではない。Effectをつなぐための記法だ。Seseragiが何でも「順次実行する文」に戻ったわけではない。

doと他の記法の関係

前の結果に依存する合成と、独立した値の合成は同じではない。 do 、 >>= 、 <*> を知りたくなったら、型・失敗・Effectの文脈と一緒に見ていこう。
