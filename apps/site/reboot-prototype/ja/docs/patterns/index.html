02 / PATTERN MATCHING

データとmatch

分岐するときも、式のままでいい。 match は値の形を調べ、一致した枝からひとつの値を作る。

結果を選ぶのも、式。

FizzBuzzなら、3と5で割った余りをまとめて調べればいい。 match の各枝は文字列を返すから、関数全体の結果にもなる。

fizzbuzz.ssrg
Playgroundで試す ↗ 
fn fizzBuzz number: Int -> String =
  // A tuple lets one match classify both divisibility rules.
  match (number % 3, number % 5) {
    (0, 0) -> "FizzBuzz"
    (0, _) -> "Fizz"
    (_, 0) -> "Buzz"
    _ -> `${number}`
  }

pub effect fn main = for number <- 1 ..= 30 {
  println $ fizzBuzz number
}
1 2 Fizz 4 Buzz Fizz …

(0, 0) は3でも5でも割り切れる場合。 (0, _) なら3だけを見て、2つ目は問わない。 _ は残りすべて。 分岐の外に return を置かなくていい のが面白いところだね。

値を作るところと、表示するところ。

fizzBuzz は文字列を返すだけ。 main では for で範囲を回り、 println $ fizzBuzz number で結果を出力している。値を計算する部分とEffectが分かれている。
