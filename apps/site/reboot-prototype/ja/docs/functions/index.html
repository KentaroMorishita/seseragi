01 / FUNCTION APPLICATION

関数と記法

関数を一つずつ書いて、必要になったら組み合わせる。Seseragiの関数は、値として渡したり、引数を途中まで与えたりできる。

関数は、小さな約束から。

文字列の両端の空白を取り、小文字に揃えたい。こんな処理を毎回書くより、 ひとつの関数として名前を付けよう。

functions.ssrg
Playgroundで試す ↗ 
import * as text from "std/text"

fn key name: String -> String = text.toLower (text.trim name)

fn で定義して、 name: String を受け取り、 String を返す。 = の右側は式。 return を書く必要はない。

空白で、値を渡す。

key " Build " のように、関数名のあとへ値を続ける。括弧で囲んだ引数リストではなく、 値をひとつ渡す関数適用 なんだ。

途中まで渡しても、関数のまま。

今度は、検索文字列が名前の先頭に含まれるかを調べよう。 matches には検索語と候補の二つが必要。でも検索語だけ先に渡すこともできる。

function-values.ssrg
Playgroundで試す ↗ 
fn matches query: String -> name: String -> Bool =
  text.startsWith (key query) (key name)

let builds = matches "b"
let choices = arrays.filter builds commands

matches "b" が返すのは、候補の名前を待っている関数。これを filter に渡せば、検索条件をもう一度書かなくていい。

関数適用の記法を確認する

fn f x: A -> B = ... は引数型と結果型を明示する。 f value が関数適用で、引数が残れば関数値になる。詳しい型規則を必要とする場面では、現行のコンパイラと仕様を正本として確認しよう。
