Guide / 関数と記法
01 / FUNCTIONS AS VALUES

関数は、使い切らなくてもいい。

Seseragiで関数を理解するなら、まず知っておきたいことがある。関数そのものが値だということ。これは「引数を省略できる」という便利機能の話だけじゃない。小さな関数をつないでいくときの土台なんだ。

たとえば、検索条件を使い回したい。

コマンドを絞り込む場面を考えてみよう。検索語と候補のどちらも大文字・小文字や余分な空白に左右されたくない。まずは、その部分に小さく名前を付ける。

01 / 抜粋：文字列を揃える
import * as text from "std/text"

fn key name: String -> String = text.toLower (text.trim name)

key の責任は文字列を揃えることだけ。検索も、画面表示も知らない。text.trim で両端の空白を取り、text.toLower で小文字にする。この順番を関数としてひとつに閉じ込めた。

次に「検索語で始まるか」を調べよう。検索語と候補名、2つの値が必要になる。

02 / 抜粋：条件を関数にする
fn matches query: String -> name: String -> Bool =
  text.startsWith (key query) (key name)

ここでの String → String → Bool は、まとめて2つの値を受け取る箱を意味しているわけじゃない。文字列を1つ受け取って、次の文字列を受け取る関数が得られるという型なんだ。

残りの引数を待つ関数を作る。

検索語が "b" に決まったら、先に渡してしまおう。

03 / 抜粋：同じ条件を再利用する
let builds = matches "b"
let choices = arrays.filter builds commands
let shortcuts = arrays.filter builds ["bundle", "run"]

builds は String → Bool の関数。だから arrays.filter にそのまま渡せる。検索対象のリストが増えても、判定方法をコピペする必要はない。関数を作って、その関数を別の関数に渡しているわけだ。

全体をつなげると、こうなる。

ここまでは部分的なコードだったので、実行できる形でも見てみよう。main は結果を表示するEffectを返す。一方、key や matches は文字列と真偽値を計算するだけの純粋な関数だ。

chapter-function-values.ssrg / 完全なプログラム
Playgroundで動かす ↗
import * as text from "std/text"
import * as arrays from "std/array"

fn key name: String -> String = text.toLower (text.trim name)
fn matches query: String -> name: String -> Bool =
  text.startsWith (key query) (key name)

let commands = [" Build ", "bundle", "CHECK", "run"]
let builds = matches "b"
let choices = arrays.filter builds commands
let shortcuts = arrays.filter builds ["bundle", "run"]

pub effect fn main = do {
  println (show choices)
  println (show shortcuts)
}

実際に choices を見れば、" Build " と "bundle" が残る。検索語を "c" に変えてみるとどうなるだろう？ さっきの関数は、そのまま使える。

この設計の何がうれしいのか。

「文字列を揃える」「一致を判定する」「配列を絞る」。それぞれが独立した仕事になった。ひとつの巨大な検索関数を作るのではなく、必要なところで組み合わせる。これがSeseragiの関数を読んでいくときの基本的な感覚になる。

ちなみに matches "b" が関数のまま残るのは偶然じゃない。Seseragiでは複数の引数を取る関数が、型の上でも最初からカリー化されている。引数は左から順に適用されるので、その性質を日常的に利用できる。

ちょっと寄り道：JavaScriptで同じ型の形を書くなら？

JavaScriptなら (query) => (name) => ... のような関数を自分で書ける。Seseragiは、この「関数を返す関数」の形が複数引数の関数宣言にも自然に現れる。大事なのは記号の短さより、途中の関数をそのまま再利用できることだね。
