Notation reference

Need to remember an operator? Jump directly to it. For exact type rules and constraints, follow through to the relevant article and compiler specification.

fn
Declare a function

↗

match
Produce a value by matching

match (number % 3, number % 5) { … }

↗
$
Apply to the right-hand expression

map badge $ arrays.filter (matches "b") commands

↗
|>
Follow transformations from a value

commands |> arrays.filter (matches "b") |> map badge

↗
<$>
Map within a context

badge <$> picked

↗
