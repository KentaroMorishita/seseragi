Function application

Function application puts an expression after the function with whitespace. Look up association, partial application, types and evaluation here.

SyntaxTypes and curryingEvaluationUnit and type argumentsSources

Syntax and association

add 1 2 means (add 1) 2. A comma-separated add(1, 2) is not the language's multi-argument call syntax.

f valueApply one value to a function
add 1 2Left associative — (add 1) 2
identity<String> valueType arguments attach to the callee

Types and partial application

Supplying only part of the arguments leaves a function waiting for the rest. add has type Int -> Int -> Int; add 1 has type Int -> Int. That follows from nested one-argument functions.

The complete program compares a direct call with a partially applied function.

pilot-currying.ssrg
Try in Playground ↗
fn add left: Int -> right: Int -> Int = left + right

let direct = add 1 2
let addOne = add 1
let answer = addOne 2

pub effect fn main = println `${direct}, ${answer}`
Output3, 3

Evaluation order

Arguments are evaluated once, from left to right. A function body is evaluated when applied. An Effect's execution boundary is a separate concept.

Unit and type arguments

A declaration such as fn clock -> Instant = ... has an unnamed Unit parameter; call it with clock (). Type arguments attach to a name without whitespace, as in identity<String> value.
